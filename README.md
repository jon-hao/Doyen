# Doyen

网页版相机：打开即取景，底部快门拍照，可分享/保存到相册。

## 功能

- 全屏相机预览、快门拍照
- 变焦：倍率按钮 + 转盘无级 + 双指捏合
- 若 Safari **开放**多镜头/`zoom`，会尽量走硬件；否则自动用数字变焦
- 打开相机后会提示当前是「硬件」还是「数字变焦」

## 在线使用

https://jon-hao.github.io/Doyen/

1. 轻触开启相机并允许权限  
2. **自动检测**：系统变焦 zoom、是否可切换物理镜头  
3. 查看结果后点「进入拍摄」  
4. 变焦 / 拍照 / 分享保存


## 重要限制（iPhone Safari）

多数 iPhone 上，网页**无法稳定**：

- 切换超广角 / 主摄 / 长焦物理镜头  
- 调用系统硬件变焦（`MediaTrackConstraints.zoom`）

Safari 通常只给一个虚拟「后置相机」，由系统自己决定镜头。  
这是平台限制，不是页面没写。要稳定控制多镜头，只能做**原生 App**。

页面底部状态行会显示 Safari 实际暴露的能力，便于确认。
