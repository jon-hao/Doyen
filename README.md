# Doyen

网页版相机：打开即取景，底部快门拍照，可分享/保存到相册。

## 功能

- 全屏相机预览、快门拍照
- **前后摄像头切换**
- 简单倍率：`1x` / `2x`（数字变焦；若系统支持 zoom 会尝试调用）
- 同意权限后先检测能力，再进入拍摄

## 在线使用

https://jon-hao.github.io/Doyen/

1. 轻触开启相机并允许权限  
2. 查看能力检测结果，点「进入拍摄」  
3. 可用右下角按钮切换前置/后置  
4. 拍照后在分享菜单里选「存储图像」

## 说明

已去掉转盘搓变焦。iPhone Safari 通常无法切换超广角/长焦物理镜头。
