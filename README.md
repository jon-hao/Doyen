# Doyen

网页版相机：打开即取景，底部快门拍照，可分享/保存到相册。

## 功能

- 全屏相机预览
- 底部快门拍照
- 变焦：
  - `.5 / 1x / 2x…` 点击切换
  - **转盘无级变焦**（拖动弧形转盘）
  - 双指捏合连续变焦
  - 在浏览器暴露多镜头时，按倍率尽量切换超广角 / 主摄 / 长焦
- iPhone 优先弹出系统分享（可存到「照片」）

## 在线使用

https://jon-hao.github.io/Doyen/

1. 首次轻触屏幕，允许相机权限  
2. 用转盘或倍率按钮变焦，快门拍照  
3. 分享菜单里选「存储图像」

## 说明

网页无法 100% 复刻系统相机。多镜头切换依赖 Safari 是否把超广角/长焦列为不同 `deviceId`；若不暴露，则会在同一镜头上做系统 `zoom` 或数字变焦。转盘在镜头交界处带滞回，减少来回抖切。
