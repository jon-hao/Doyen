# Doyen

网页版相机：打开即取景，底部快门拍照，可分享/保存到相册。

## 功能

- 全屏相机预览
- 底部快门拍照
- 变焦：`.5 / 1x / 2x…` 快捷切换（机型支持时），双指捏合连续变焦
- iPhone 优先弹出系统分享（可存到「照片」）；否则下载 JPG

## 在线使用

部署后用手机 Safari 打开（需 HTTPS）：

https://jon-hao.github.io/Doyen/

1. 首次：轻触屏幕，在系统弹窗里允许相机（之后一般会记住）  
2. 点底部快门拍照；可用下方倍率或双指捏合变焦  
3. 在系统分享里点「存储图像」（网页无法静默写入相册，这一步省不掉）

## 本地预览（电脑）

```bash
python3 -m http.server 8080
```

浏览器打开 http://127.0.0.1:8080

> 说明：网页变焦优先使用系统 `zoom` 能力；若不支持则回退为画面数字变焦。`.5x` 超广角取决于手机是否向浏览器暴露该能力。
