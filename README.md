# Doyen

**Doyen**（谐音「导演」）— 第一次拍照也能像摄影师一样出片。

不是又一个 AI 相机，而是一场拍摄的 **AI 导演**：生成 Shot List，逐步指挥摄影师与模特，直到整组照片完成。

## 产品闭环

```
选择风格 → 选择场景 → Shot List → AI 导演
→ 摄影师执行 / 模特执行 → 拍摄 → 是否合格 → 下一镜 → 整组完成
```

## 环境要求

- macOS + Xcode 15+
- iOS 17+ 模拟器或真机
- 免费 Apple ID 即可真机调试（无需付费开发者账号）

## 打开项目

1. 用 Xcode 打开 `Doyen.xcodeproj`
2. 顶部选模拟器或你的 iPhone
3. 点 Run（▶）

首次真机运行：在 iPhone **设置 → 通用 → VPN 与设备管理** 中信任开发者证书。

## 关于 Xcode 许可

若命令行提示未同意许可，在「终端」执行：

```bash
sudo xcodebuild -license
```

按提示输入密码，读完后输入 `agree`。
