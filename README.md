# Doyen

网页版相机：进页环境检测 → 全屏取景拍照；支持保存/分享。可开 **辅助拍摄**，实时框出画面主体。

在线使用：https://jon-hao.github.io/Doyen/

## 功能

- 环境检测：HTTPS、相机 API、辅助拍摄可用性
- 全屏取景（JS cover，减少 iOS 黑边）、快门、前后摄像头
- 风景 / 人像焦段预设（默认风景 · 广角）
- **辅助拍摄**：本地轻量目标检测，绿框跟随主体；资源约 7MB，可缓存后续静默加载

## 辅助拍摄

### 引擎

- MediaPipe Tasks Vision · **EfficientDet-Lite0**（约 6.9MB，CPU/WASM）
- 首次下载显示「下载资源 x%」；已缓存则进页静默热启动，点一次即可开关，不再闪下载文案
- 框随镜头近实时更新（检测间隔约 80ms 量级）

### 模式策略（分开）

| 模式 | 框什么 | 选主体依据 |
|------|--------|------------|
| **风景** | 独立主体（花、车、建筑小品等；不优先路人） | ① 完整度（少贴边裁切）② 画面中心 / 三分法兴趣点 ③ 框内相对周围的颜色对比度（轻量显著性代理）④ COCO 类别先验（主体加分、沙发/桌面等场景平面降权）⑤ 中等尺寸甜区 |
| **人像** | **只框人**；无人则不画框 | ① 身体完整度 ② 接近中心 ③ 合适占比 + 人形长宽比；跟踪时 IoU 连续加分 |

策略参考：显著目标检测（SOD）与移动端实时构图评分思路——突出前景、完整主体、中心/三分法；人像参考单人检测排序（完整度、面积、跟踪位置）。未引入 U²-Net 等额外 SOD 模型，以控制 iPhone 内存。

### 使用注意

- 请用**后置镜头**；前置会提示不可用
- 推荐较新的移动 Safari / Chrome；首次需联网拉模型，之后可离线热启动（同源缓存）
