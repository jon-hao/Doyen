# Doyen

网页版相机：进页环境检测 → 全屏取景拍照；支持保存/分享。可开 **辅助拍摄**，实时勾勒主体并指导风景构图。

在线使用：https://jon-hao.github.io/Doyen/

## 功能

- 环境检测：HTTPS、相机 API、辅助拍摄可用性
- 全屏取景（JS cover，减少 iOS 黑边）、快门、前后摄像头
- 风景 / 人像焦段预设（默认风景 · 广角）
- **辅助拍摄**：本地轻量检测 + 轮廓分割 + 风景构图引导；首次约 13MB，可缓存后静默热启动

## 辅助拍摄

### 引擎

- **EfficientDet-Lite0**（约 6.9MB）：选主体 / 跟踪
- **MagicTouch Interactive Segmenter**（约 5.9MB）：主体轮廓掩码
- **构图评分**（本地启发式，无额外模型）：三分法 / 视觉平衡 / 尺寸甜区
- 首次下载显示「下载资源 x%」；已缓存则进页静默热启动，点一次即可开关
- 轮廓：绿色描边 + 更浅的半透明绿色填充

### 交互

- 开启后点画面：若点击附近有可识别主体，则锁定该主体（优先级最高）
- 取景区点击：类似 iPhone 的半透明对焦框闪现（按钮区域不触发）
- 切换焦距 / 镜头 / 风景·人像 / 横竖握：清空旧结果并重新分析
- 镜头小幅晃动：框体死区稳定，避免抖动

### 风景构图引导（当前重点）

算法参考：

- Liu et al. *Optimizing Photo Composition*（三分法、视觉平衡、尺寸区域）
- Sensors 2020 *Photo Composition with Real-Time Rating*（主体重心距三分点实时评分）
- 实时 view adjustment 思路：把主体移向最优兴趣点，并建议变焦

开启辅助且处于**风景模式**、已识别主体时：

1. **细边框**围住整个取景，颜色随评级变化  
   - **B** 红色：构图较差  
   - **A** 黄色：构图一般  
   - **S** 绿色：构图良好  
2. 画面中央四个半透明箭头：示意应朝哪边移动镜头，使主体靠近三分点 / 中心构图目标；评级字母叠在箭头中间  
3. 主体占比偏离甜区时，顶部半透明提示「建议切换至 ×× · ××mm」，并短暂高亮对应焦段按钮  

人像模式暂不启用上述构图引导（后续可扩展）。

### 模式策略

| 模式 | 框什么 | 选主体依据 |
|------|--------|------------|
| **风景** | 独立主体（不优先路人） | 完整度 → 中心/三分法 → 对比度 → 类别先验；含构图评级与移镜/焦段建议 |
| **人像** | **只框人** | 完整度 → 中心 → 占比与人形比例 |

### 使用注意

- 请用**后置镜头**
- 推荐较新的移动 Safari / Chrome；首次需联网拉模型

## 本地文件

| 路径 | 说明 |
|------|------|
| `index.html` | 相机 UI、构图引导叠加层 |
| `coach-engine.js` | 检测 + 分割 + 点击锁定 / 防抖 |
| `composition-coach.js` | 风景构图评分、移镜箭头、焦段建议 |
| `models/efficientdet_lite0.tflite` | 目标检测 |
| `models/magic_touch.tflite` | 交互式轮廓分割 |
